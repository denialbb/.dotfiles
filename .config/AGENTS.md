# AGENTS

## Communication Style

- when reporting information back to me, be extremely concise and sacrifice
  grammar for the sake of concision. Use bullet-points when appropriate

## Code Writing

- focus on clean code and correctness
- no code smell
- clarifying comments

## Notifications & Reporting
- Use the `tg-send` skill (`~/.local/bin/tg-send`) to communicate with the user when running long sessions, when an extended background task completes, or when reporting an issue.
- Always include your model name and the current session/project context in the notification to the user.
